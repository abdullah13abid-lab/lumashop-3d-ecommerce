# TaskMaster - Todo List Application

A modern, feature-rich to-do list application built with React and Vite. Complete with local storage persistence, dark theme, and beautiful UI.

## ✨ Features

- ✅ **Add/Edit/Delete Tasks** - Full CRUD operations
- ✅ **Local Storage** - Data persists across browser sessions
- ✅ **Task Completion** - Mark tasks as done
- ✅ **Priority Levels** - High, Medium, Low priorities
- ✅ **Due Dates** - Set deadlines for tasks
- ✅ **Categories** - Organize tasks by category
- ✅ **Search & Filter** - Find tasks easily
- ✅ **Statistics** - View task completion stats
- ✅ **Dark Theme** - Eye-friendly interface
- ✅ **Responsive Design** - Works on all devices
- ✅ **Undo/Redo** - Revert recent changes
- ✅ **Export Tasks** - Download task list as JSON

## 🛠 Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** CSS3 + Tailwind CSS
- **Storage:** Browser Local Storage
- **Icons:** Unicode Emojis

## 📦 Installation

```bash
cd todo-app
npm install
npm run dev
```

Visit **http://localhost:5173** in your browser.

## 📖 Usage

1. **Add Task:** Type in the input field and press Enter or click "Add Task"
2. **Complete Task:** Click the checkbox to mark as done
3. **Edit Task:** Click the edit icon to modify
4. **Delete Task:** Click the trash icon to remove
5. **Filter:** Use the filter buttons to view specific task types
6. **Export:** Click "Export" to download your task list

## 📱 Responsive

- Mobile: 320px and up
- Tablet: 768px and up
- Desktop: 1024px and up
